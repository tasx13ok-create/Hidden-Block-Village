# Original shinobi skins

Original 64x64 Minecraft skins (classic arms, with an outer layer for hair, hoods and gear) in an anime-ninja style. Every character, village symbol, mask and outfit here is an original design for Hidden Block Village. None are copies or edits of characters or textures from any show or other mod.

| File | Character |
|---|---|
| `kaito_ember_genin.png` | Ember Ward genin: rust spiky hair, ember sash, wrapped forearms and shins |
| `sayo_current_kunoichi.png` | Current Ward kunoichi: teal braid, high-collar coat, wave band |
| `garran_flint_jonin.png` | Flint Ward jonin: buzz cut, olive vest with pouches, red shoulder guard, nose scar |
| `lantern_sage_dawn.png` | Dawn Ward sage: white-gold robe, straw hat, white beard |
| `rook_dusk_operative.png` | Dusk operative: grey plate over a black suit, original crow mask with violet marks |
| `ash_regent_boss.png` | Ash Regent boss: smouldering cloak, horned helm, ember eyes and ash veins |

`preview.png` shows the front and back of each skin.

To regenerate, run this from the repository root:

```
python3 tools/skins/skins_make.py tools/skins content/skins
```
