# Original500-block Naruto stadium architecture

`architecture-v1.json` supplies the versioned enclosing-stadium identities,
500×250×500dimensions, existing inner-court dimensions, palette and the actual
loaded bowl/tower parameters. `tools/arenas/geometry.py` constructs all five.
The owner's later clarification means the **stadium itself** spans the full
500×500×250; the older220..340bowl instruction now describes only the useful
inner combat/spectator district. Grounded structural enclosure, outer bleachers,
occupied service galleries and real rooms extend across the stadium footprint.

The silhouettes and block sculptures are original procedural adaptations:
Leaf timber/plaster/roots, asymmetrical Cloud fortress banks, circular sandstone
scholar bays/gourd, marine fin/shark-mouth/piled stands and a grounded octagonal
Uchiha fan/moon-gate citadel. No reference artwork, NPC, schematic or world cells
are copied. Minecraft1.12.2vanilla materials retain their native provider assets.

The first full-size exterior was rejected in visual review because its filled
retaining facades looked like blank boxes. Version1.2cuts actual64-block-deep
arcades through that substructure, retaining40-block bearing bays and lintel
beams. The exterior galleries have real floors and connected stair flights;
Leaf timber/plaster frames, colossal Cloud colonnades and separated plates,
Sand scholar galleries, open marine piles and grounded Uchiha buttresses extend
their regional identity down the facades. Earlier exports remain preserved.

The generator records exact standing anchors, densely sampled paths, service
room entries, actual normal-half stair samples, owned source-fluid volumes,
light sources and original geometry/config hashes. Exported semantic last-writer
layers let the independent reader measure the actual stadium architecture
separately from the full plot's terrain or padding. The geometry regression
suite reopens all five full-size compressed outputs and checks their true
architectural extents, substantial outer construction, routes, source fluids,
gravity, all anchors and rooms.

These are offline construction checks. Real boss behavior, collisions of
native forms, light after updates, protection against native direct block edits,
fluid updates, breathing, boats, lifecycle/rewards and client presentation retain
their own native acceptance gates. Wood blocks remain native flammable wood;
arena fire/jutsu protection must pass its actual runtime tests. Gallery lights
are real source blocks, but a source count does not establish native block-light
levels or shader acceptance.

The native fixture rejected dark stair samples because vanilla stairs have
opacity255. Version1.2.1checks actual AIR/glass light paths to every dense route
center and adds exposed emitters touching existing bearing blocks outside all
walking and giant-form envelopes. It keeps the real stairs intact. Each added
fixture records its source bytes, attachment and a transparent path of at most
seven edges; the independent regression reopens and checks those cells.
This conservative light-path design still requires native block-light measurement
on the final matching export.

Kisame's optional prison is a separate15×15basin on the northeast dry island.
It retains two3-wide physical stair exits over the rim and leaves the main boss
anchor and approach clear. Metadata records the bounded two-layer fill target.
The runtime must journal only eligible baseline air, preserving the real solid
egress stairs; native containment, drowning recovery and restart checks remain
mandatory.
