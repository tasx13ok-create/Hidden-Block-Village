Dungeon Guard 1.2.0 — easy setup
Minecraft Java 1.12.2

INSTALL THE ONE JAR

1. Stop your server and back up the world.
2. Put this JAR in the server's mods folder:
   Dungeon-Guard-1.12.2-1.2.0.jar
   Remove any older Dungeon Guard JAR. Keep your world, dungeon-guard folder
   and saved snapshots.
3. Put the SAME JAR in each player's client mods folder for the illustrated
   dungeon/boss banner. Players without it can still join and see plain titles.
4. Start the server and join as an operator.

OPEN YOUR MENU

Type /dungeon

Open chat with T to click the buttons. Use /dungeon setup for the guided steps.
Existing dungeons and spawn settings carry over; set up only new areas.

SAVE A NEW DUNGEON

Start with the finished, undamaged dungeon already in your world.

1. Stand near your existing Overworld spawn Waystone, look at it, and type:
   /dungeon setspawn
2. Get the selection stick:
   /dungeon wand
3. Hold that stick. Left-click a low corner block, then right-click the
   diagonally opposite high corner block. Include the whole dungeon and its
   fighting space inside that box.
4. Save it and name its banner in one command:
   /dungeon create fire Fire Dungeon
   Change the element and display name for your dungeon.
5. Keep everyone out while it saves. Wait for the Ready message before fighting.

ADD A BOSS ROOM

Select the boss chamber's two corners with the stick, entirely inside a saved
dungeon. Then type /dungeon boss followed by the actual boss's name.
The mod finds the parent dungeon for you. This labels the room; your existing
boss system handles spawning the boss.

EVERYDAY USE

/dungeon       Open the menu and see what to do next.
/dungeon spawn Return to the spawn Waystone.
/dghud off     Hide your banner. Use /dghud on to show it again.

After the LAST player leaves, the dungeon automatically rebuilds from its
saved clean copy. Outside terrain stays protected; operators can build.
Saved chest contents return too, so captured loot will restock.
