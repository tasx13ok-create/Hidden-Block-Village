Adapt to that actual cache/render route, preserving physical stacks, native count overlays, cursor/nonce receipts, focus/input and the current HUD18owner telemetry. `HotbarFx.pushBody` adds hurt shake even when motion=false; fix that and reset all spring/weather/particle/cast state on player/world/connection changes. Grant authentic issued gear through the owner issuer and unlock lessons through the reviewed profile APIs so all eligible moves are reachable; do not create unissued NBT gear. Do not turn preview kills/practice into normal mission/trial/mastery rewards. Survival/adventure continues paying the canonical native resource. Actual native tests must cover Creative switch during a pending ticket, respawn/logout, absent/unready provider and return to paid Survival. This audit made no such source changes.
