# Character armor and weapon art addendum

The owner wants all recognizable character equipment across the supplied mod pack, including worn armor and held weapons as well as inventory icons. The earlier current-Vale list uses generic equipment names and must not be treated as a verified character-by-character replacement map.

`collaboration/sonnet-art/SONNET-EQUIPMENT-ADDENDUM.txt` is the pasteable instruction. `06-ARMOR-AND-WEAPONS.txt` enumerates 673 reference model/visual-state rows absent by name from the current Vale checklist: 342 armor/wearable rows and 331 weapon rows. Alternate, blocking, thrown, extended and GUI forms are separate art states, not extra unique weapons. All these model paths already appeared in the original full reference appendix; this is a focused extraction, not 673 newly discovered runtime items.

`07-EQUIPMENT-NAME-CORRECTIONS.txt` adds nine corrected localized names/base aliases: the six village ninja headbands, Kabuto Robe, Giant Folding Fan and Retractable Spear. These correct existing model jobs, not nine additional confirmed items. `08-WORN-ARMOR-AND-WEAPON-ART.txt` lists 256 worn-armor texture paths/dimensions and held-model integration work. `equipment-inventory.json` carries exact source/model IDs, classification evidence, localization, texture references and overlap flags. It also retains 12 equipment infrastructure/example rows outside the focused 673-row list.

`tools/build_equipment_handoff.py --reference-dir <private-mods-directory>` verifies all 49 original JAR hashes against the original art index and joins item model metadata with Java class inheritance/resource literals. It does not execute reference code. Reviewed explicit weapon families cover special non-sword weapons and the Varied Commodities registrar. Unused generated language keys are not accepted as proof of extra armor slots. Private custom skins and runtime NBT variants remain unenumerated.

The ignored five-file ZIP is `exports/Sonnet-Art-Handoff/Hidden-Block-Village-Armor-Weapons-Addendum.zip`, SHA256 `b0429dc3123228ad9ee7e3efd6abff563ddc8b10f90cd1b8e0cc624ba80f67fa`. Its CRC, exact entry set and byte identity with the five text/JSON sources passed. Coverage spot checks include Naruto, Sasuke, Kakashi, Akatsuki, Gaara, Zabuza, Haku, Boruto, Kawaki, Isshiki, Kabuto, Itachi, Samehada, Kubikiribocho, Hiramekarei, Kusanagi, Chojuro and Orochimaru. Third-party artwork and JAR payloads are not included. Sonnet should create original assets with a per-ID completion manifest, preserving gameplay/save identifiers.
