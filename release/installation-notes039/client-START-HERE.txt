INSTALL
1. Choose Import > Import Profile .zip > Choose .zip file in CurseForge.
2. Select the completed Client-Candidate.zip, or the matching server's
   client-install/Client.zip. They contain the same reviewed client bytes.
3. If bundled files are flagged, review the expected roster below and the
   candidate's file identities. Select All Files for this reviewed custom
   package after acknowledging the prompt. Its manifest has files: [] and
   bundles the JARs in overrides/mods; CurseForge Files Only can omit them.
4. Confirm all eleven JARs, Minecraft 1.12.2 and Forge 14.23.5.2859.
5. Launch the new profile and add the actual server address and port in
   Multiplayer. This profile contains no preconfigured servers.dat.
